  1. Pool. Each chain shows its outputs and how many links each output has. External sources such as MIDI have their own colour.
  2. Inputs. They are normal parameters. A hand value, a MIDI fader or another chain can drive each one. The line under a value shows what drives it.
  3. Outputs. Each output shows its live level and the targets it drives, with the colour of the target kind.
  4. Assign. Right-click a parameter, then Modulate with, the chain, the output. Here the user links Beat FX . Jitter to the Angle of Modifier Rotate.
