Modulation pool

One pool of modulators for the project. Drag a modulator from the pool onto a value to link it. Each link has its own amount.

Tree

Inspector

Modulation

  1. Drag a chip from the pool onto a value. The value gets the one "modulated" colour and a ring. (Serum, TouchDesigner)
  2. The ring shows the amount of the link. Turn the mouse wheel on the ring to change it. (Serum, Bitwig)
  3. The matrix lists each link: source, target and amount. (Logic Pro, Serum)
  4. Click a chip: its targets light in the tree, the inspector and the matrix. (Bitwig)
  5. The tree shows a category row only when its list has items, with a gap between kinds. A layer shows its lists, with Add and Hide, in the inspector. (Blender)
