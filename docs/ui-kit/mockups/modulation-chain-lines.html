The order of this list is the order on the canvas and outside the chain.

Colour follows a hierarchy, as a transit map. The outputs come first: each output is a line with its own colour. Every cable and node takes the colour of the one output it feeds, so at rest you see which nodes serve Breath, Pulse or Step. A part that feeds several outputs, as the Kick, is light neutral, as a shared station.

A node kind is its icon shape only. Press an output to light its whole line: the other lines step back. Pulse is selected. Press a node to light its own cables, press the empty canvas to clear.
