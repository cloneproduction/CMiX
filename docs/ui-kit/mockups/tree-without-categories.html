Tree without categories

One sample project, six times. The first panel is the tree today, with a row for each list. The other four have no category rows: the items of an owner follow each other in a fixed kind order. Click a row to select it.

  1. A: only the icon and its colour tell the kind. The most compact.
  2. B: a small gap between two kinds. The blocks show without any text.
  3. C: a small label in the kind colour above each block. It is not a row: you cannot select it, drop on it or hide it.
  4. D: a line in the kind colour on the left of each block, at the indent of the items.
  5. E: the middle ground. An empty list has no row, so a drop into it needs a place that shows only during a drag.
  6. In every option, a drag of a filter can only land in a block of filters. An empty list keeps one drop place where its block would be.
