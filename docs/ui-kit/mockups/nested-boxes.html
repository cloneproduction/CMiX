Nested boxes

A composition holds layers and groups. A group holds layers and groups. A layer holds its items.

  • Drag any box or item. A box moves with all it holds. Alt copies, Esc cancels.
  • Click a row to select it. Click the arrow of a box to collapse it to one row with its counts.
  • Double click a box to open it as the root. Click a name in the path at the top to go back up.
  • Drop on a name in the path to move a thing up to that level.
  • "+ Layer" adds, the trash removes, a drop below the last composition makes a new one.
