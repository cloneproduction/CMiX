Stack layouts

Four ways to show and move compositions and layers. Drag a layer or a composition. Hold Alt during a layer drag to copy it. The output under each panel shows the blend of the drop place before you release. The top layer of a list draws in front. Esc cancels.

A. Tree

Today: one row for each composition and layer, with an indent.

B. Board

Each composition is a column, its layers are cards in blend order. Move a layer across, or drag a column. (Kanban, Canvas of lists)

C. Nested boxes

A composition is a box that holds its layers. The box grows when a layer enters. (Lists in lists, Layout editor)

D. Board with tools

Drag "+ Layer" into a column to add. Drop on the trash to remove. Drop right of the last column for a new composition. (Insert and remove, When far)
