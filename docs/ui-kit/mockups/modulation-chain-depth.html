The order of this list is the order on the canvas and outside the chain. Every port is a number: the list shows its range.

Colour follows depth, as the composables of the tree: the same wheel of six, in the same order. The chain inputs are stage 0 and have the colour of a composition. A node is one stage after the deepest node that feeds it. Two connected stages never share a hue.

Every port is a number, one float in and one float out, so every pin is the same round shape. A cable has the colour of the stage it leaves: an input pin shows the stage before, an output pin its own stage. The Kick picks its sound in the node and gives one envelope. The LFO is selected.
